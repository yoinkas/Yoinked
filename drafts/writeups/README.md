# Local writeup drafts

Writeup Studio saves editable JSON in `data/`, site-styled HTML in `previews/`,
and uploaded files in `media/`.

Run `npm run serve` from `tools/writeup-studio`, open `http://127.0.0.1:3000`,
and use **Save to Yoinked**. Draft previews include `noindex` and are not added
to the public post list.
